产品上架 / 修订 / 下架

批量上架从本地文件夹识别多个产品，逐站执行国际站复制、Product Description 翻译、Overview/Specification 和语言包更新；修订模式只更新已有产品；下架模式只关闭 Searchable 并将 Type of listing 设为 No Set Uptime。所有写操作都必须先预览。

每个产品需要一份 Datasheet.xls/xlsx 和一份 Specifications.xls/xlsx。支持“每个产品一个子文件夹”，或在同一文件夹使用“产品名 Datasheet.xlsx / 产品名 Specifications.xlsx”。Datasheet 必须包含 Product Description 行及各站点译文。

语言包操作顺序：先按目标站点确定 Datasheet 语种列（例如法国站取 French、德国站取 German）→ 下载该站当前语言包 → 用语言包第 3 列字段名匹配 Datasheet → 保留第 4 列原文，并用本站对应语种覆盖第 5 列译文 → 上传新语言包 → 再次下载回读验证。
