## eufy Patterns / eufy 做法

- Uses a "Quick Intro" feature-card strip before long storytelling.
- Turns features into short claims: dual camera clarity, solar power, 360 protection, AI tracking, flexible installation.
- Uses comparison and FAQ near the bottom to organize model information.
- Uses visual feature demonstration for camera movement and coverage. SoloCam S340 explains dual-camera clarity, 8x hybrid zoom, 360-degree pan, 70-degree tilt, and AI tracking as a sequence rather than a plain spec list. Indoor Cam E30 groups 4K clarity, efficient viewing, 360 coverage, AI detection/tracking, night vision, two-way audio, storage, and smart-home integration under a Quick Intro area. eufyCam S4 explains bullet-to-PTZ tracking, simultaneous wide/close views, and auto-framing/auto-zoom as separate proof moments.

Takeaway:

Use eufy's information layout when the page needs clearer feature grouping, quicker product orientation, or a more readable model-comparison structure. Exclude pricing, fulfillment, warranty, reviews, and checkout patterns unless explicitly requested.

适合借鉴 eufy 的地方：购买路径、价格和保障信息、快速功能卡片、评测背书、FAQ 和对比表。

Interaction takeaway:

Use eufy as a reference for feature explanation patterns: make zoom, 360-degree coverage, auto-tracking, and dual-view functions visible through a demo module. Do not bury these features in icon grids.

交互参考：变焦、360 度覆盖、自动跟踪、双视角这类功能，应该用可视化演示模块表达，不要只放在图标列表里。

## Reolink Patterns / Reolink 做法

- Uses a sticky product subnav: Overview, Specs, Accessories, FAQs, Review.
- Hero copy is benefit-dense and specific: 4K, 180-degree view, color night vision, longer battery, local storage.
- Each core feature has a strong proof module: 180-degree view, ColorX night vision, Wi-Fi 6, smart detection, local storage.
- Converts technical points into visible metrics: 30% more battery life, 12 extra days, storage capacity.
- Provides extra feature grids and creator/review sections.
- Uses state switching to keep related visual modes in one place. RLC-823S2 switches Day Vision, Color Night Vision, and Black & White Vision; it also groups storage methods with recording-capacity proof instead of giving each method a full standalone section.
- Connects feature claims to an action model. RLC-823S2 explains 3D Zoom as framing an area in the app and having the camera zoom to it; its 360-degree section continues into preset patrol points and auto-tracking. This turns "coverage" into a controllable sequence: select an area, move to it, and keep it in view.
- Uses installation choices as a compact visual set. Argus PT Ultra presents four mounting methods as image-led options, preventing installation information from becoming a long technical block.

Takeaway:

Use Reolink's structure when the product has strong technical features that need proof, numbers, and scenario explanation.

适合借鉴 Reolink 的地方：锚点导航、强参数表达、功能证明模块、指标化文案、场景化解释。

Interaction takeaway:

- Use a segmented visual switcher for related viewing modes, such as Day / Color Night / IR Night or WDR / LDR / LDC. Change one shared scene and retain a stable comparison frame.
- Use Reolink's 3D Zoom logic for zoom-capable cameras: let the visitor select a region in a wide live-view image, then reveal the corresponding close-up. A static before/after fallback is required when the source images cannot support a believable crop.
- For pan/tilt products, add preset-point buttons such as Gate, Driveway, Porch, and Side Yard to a 360-degree coverage viewer. Each selection must update the camera orientation, coverage cone, and live-view scene; make manual drag a secondary control.
- Use tabbed storage, installation, or night-vision states only when the choices share one buyer question. Do not place unrelated features in the same tab set just to shorten the page.

交互借鉴：

- 对日视 / 全彩夜视 / 红外夜视，或 WDR / LDR / LDC 这类同一观看问题，使用分段切换。共享同一场景，保持对比基准不变。
- 对具备变焦能力的摄像头，采用 Reolink 的 “3D Zoom” 叙事：用户在广角画面框选区域，再展示该区域的放大细节。素材无法支撑真实裁切时，降级为静态前后对照。
- 对云台摄像头，在 360° 模块中增加“门口 / 车道 / 走廊 / 侧院”等预设点。切换时同步更新机身朝向、覆盖扇形和实时画面；拖拽只作为补充控制。
- 仅在选项回答同一个购买问题时使用 Tab，例如存储、安装、夜视模式；不要为了缩短页面把无关功能硬塞进同一组。

## Promotion Page Patterns / 促销页做法

- Reolink uses event framing, category anchors, and many deal blocks.
- eufy uses campaign promise, product category grouping, coupon copy, Buy Now, and Learn More.
- Both make product discovery faster by grouping deals by category rather than telling a long brand story.

Use for sale pages:

- Put discount and code above the fold.
- Group products by need, not just SKU.
- Show card-level CTAs.
- Keep rules and exclusions visible near the bottom.
