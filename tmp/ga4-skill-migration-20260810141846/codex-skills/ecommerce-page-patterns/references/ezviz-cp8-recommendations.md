# EZVIZ CP8 Recommendations / EZVIZ CP8 页面建议

Use this as a saved reference when improving the CP8 product detail page or similar EZVIZ smart entry pages.

## Current Strengths / 当前优势

- Strong feature set: 5MP, 9600mAh detachable battery, human detection, color night vision, WDR/LDC, chime, Wi-Fi 6, two-way talk, privacy zones, microSD/cloud storage, Google/Alexa.
- Page already has a full feature sequence, installation steps, storage/privacy, specs, and in-box details.
- The product is a doorbell kit, so the included chime and removable battery are practical differentiators.

## Main Issues / 主要问题

- The first viewport reads more like a spec intro than a purchase argument.
- Key feature list is long; it needs grouping into buyer-relevant themes.
- Some sections repeat battery content and reduce momentum.
- Interaction proof is weaker than eufy/Reolink: the page tells users about app alerts, voice changer, privacy, and storage, but should show more UI states.
- Technical benefits need sharper metrics and visual comparison.
- English copy has polish issues such as "Sate Storage Options" and awkward headings.

## Recommended New Structure / 建议新结构

1. Hero: "Know who's at your door in sharper 5MP detail" with product + phone alert visual.
2. Proof strip: 5MP, 9600mAh battery, chime included, human detection, local/cloud storage.
3. Doorstep scenario story: visitor, package, night, bad weather.
4. Visual clarity module: 5MP crop + WDR/LDC comparison.
5. Detection module: person arrives -> alert -> two-way talk/voice changer.
6. Power module: detachable 9600mAh battery with simple recharge steps.
7. Chime and Wi-Fi reliability module.
8. Privacy/storage module: privacy zones, microSD up to 512GB, CloudPlay, encryption.
9. Installation 3-step module.
10. Specs, in-box, FAQ, support.

## High-Impact Fixes / 高优先级修改

- Add sticky subnav: Overview, Features, Installation, Storage, Specs, FAQ.
- Add a sticky CTA or "Where to buy" bar if the region page does not sell directly.
- Replace long icon grid with 4 grouped cards:
  - See clearly
  - Detect accurately
  - Respond safely
  - Install and store easily
- Add before/after interaction for WDR/LDC and night vision.
- Add app UI mockups for alert, live view, voice changer, privacy zone, and storage.
- Add a competitor-style comparison table against older doorbells or lower-resolution models.
- Rewrite awkward headings into clear benefit language.

## Sample Heading Rewrite / 标题改写示例

- "Clearer and smarter views at your doorstep" -> "See and answer every doorstep moment in sharper 5MP detail"
- "Recharges in Seconds, Runs for Days" -> "Remove, recharge, and snap the battery back in"
- "Trusts On Your Extra-Large, Sate Storage Options" -> "Choose local or cloud storage with more control"
- "Sets Up Your Doorbell Without Any hassle" -> "Set up your doorbell in three simple steps"

## Visual Direction / 视觉方向

- Use clean white/soft gray product-detail styling for credibility.
- Use dark/night modules only for night vision and privacy/security sections.
- Use real doorway scenes, package-delivery scenes, and phone UI overlays.
- Avoid too many generic icons; each icon should lead to a feature proof module.
