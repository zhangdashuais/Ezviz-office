# Security Camera And Smart Doorbell Patterns / 安防摄像头与智能门铃页面模块

## Feature Story Modules / 功能叙事模块

Use these modules when building or reviewing security camera, smart doorbell, smart lock, and smart-home product pages.

### 1. Clarity / 清晰度

Show resolution, sample footage, zoom crop, face/package/license plate examples, and day/night comparison.

展示分辨率、样张、放大裁切、人脸/包裹/车牌细节、白天夜晚对比。

### 2. Field Of View / 视野范围

Use a scene diagram or wide-angle overlay to explain coverage. Avoid only saying "wide FOV"; show what extra area is captured.

用场景图或视野覆盖图解释能看到哪里，不要只写“广角”。

### 3. Detection / 智能检测

Show detection logic as steps: person arrives, AI/PIR confirms, phone alert appears, user responds.

用流程展示检测：有人出现、AI/PIR 判断、手机推送、用户响应。

### 4. Night Vision / 夜视

Use before/after or side-by-side modules. Include visible distance and limitations when available.

用前后对比或并排对比，最好说明有效距离和限制。

### 5. Power / 电池与供电

Make battery easy to understand: capacity, detachable or built-in, expected usage, charging steps, solar compatibility if any.

电池表达要直观：容量、是否可拆、续航场景、充电步骤、是否支持太阳能。

### 6. App Interaction / App 交互

Show the app interface, alert card, live view, two-way talk, privacy zone, detection zone, playback, and storage settings.

展示 App 界面：推送卡片、实时画面、双向通话、隐私遮挡、检测区域、回放、存储设置。

### 7. Privacy And Storage / 隐私与存储

Explain local storage, cloud storage, encryption, privacy zones, and subscription implications.

解释本地存储、云存储、加密、隐私区域、订阅费用影响。

### 8. Installation / 安装

Use a 3-step visual setup: connect, mount, configure/recharge. Show included accessories.

用三步图讲清安装：连接、安装、配置/充电，并展示包装清单。

## Copy Formula / 文案公式

Feature heading:

- English: Benefit first, feature second.
- Chinese: 场景收益优先，参数放后面。

Example:

- See Every Visitor Clearly, Even at Night
- 夜晚也能看清门前访客

Proof line:

- English: "5MP resolution + WDR helps preserve face and package detail in bright doorway scenes."
- Chinese: "5MP 分辨率 + WDR 能在强逆光门口保留人脸与包裹细节。"

CTA:

- Learn More
- Compare Models
- Buy Now
- Check Compatibility
